# 🕊️ Umut - Mazlumlar İçin Yardım Platformu

Modern, responsive ve animasyonlu tek sayfalık (one-page) yardım derneği web sitesi.

## 🚀 Özellikler

### Tasarım
- ✅ **Tam Responsive** - Tüm cihazlarda mükemmel görünüm
- ✅ **Modern Animasyonlar** - Yükleme ekranı, scroll animasyonları, hover efektleri
- ✅ **Gradient ve Glassmorphism** - Güncel tasarım trendleri
- ✅ **Parallax Efektler** - Derinlik hissi veren animasyonlar

### SEO Optimizasyonu
- ✅ Meta tag'ler (title, description, keywords)
- ✅ Open Graph tags (Facebook, Twitter paylaşımları için)
- ✅ Semantic HTML yapısı
- ✅ Robots.txt uyumlu
- ✅ Hızlı yükleme (preconnect, lazy loading)

### Fonksiyonellik
- ✅ Tek sayfalık smooth scroll navigasyon
- ✅ Mobil hamburger menü
- ✅ Otomatik sayaç animasyonları
- ✅ Yorumlar/testimonials slider
- ✅ Bağış formu
- ✅ İletişim formu
- ✅ Bülten aboneliği
- ✅ Toast bildirimleri

## 🛠️ Kullanım

### Dosyaları Görüntüleme

1. Tüm dosyaları bir klasöre koyun
2. `index.html` dosyasını bir tarayıcıda açın
3. Veya bir web sunucusunda yayınlayın

### Özelleştirme

#### Logo Değiştirme
HTML'deki logo bölümünü düzenleyin:
```html
<a href="#" class="logo">
    <span class="logo-icon">🕊️</span>
    <span class="logo-text">Umut</span>
</a>
```

#### Renkleri Değiştirme
CSS değişkenlerini düzenleyin:
```css
:root {
    --primary: #2dd4bf;    /* Ana renk */
    --secondary: #6366f1;  /* İkincil renk */
    /* ... */
}
```

#### İçerik Güncelleme
`index.html` dosyasındaki metinleri istediğiniz gibi değiştirin.
